# PLAYMAX Admin — تطبيق الإدارة

تطبيق منفصل للمالك فقط. منه تغيّر الأسعار، تضيف ماكينات جديدة بصورها، تنشر أخباراً وعروضاً، وتعدّل أسعار الشحن وأرقام التواصل. أي شيء تنشره يظهر في **الموقع والتطبيق معاً** خلال دقيقة تقريباً، بدون رفع ملفات يدوياً.

## كيف يعمل

```
تطبيق الإدارة  ──►  GitHub (ملف content.json + الصور)  ──►  GitHub Pages
                                                         ├─► الموقع
                                                         └─► تطبيق الزبائن
```

- الموقع والتطبيق يقرآن ملف `content.json` في كل مرة يُفتحان فيها، وكذلك عند الرجوع إليهما. لذلك يصل كل تحديث للزبائن تلقائياً.
- تطبيق الإدارة لا يحتاج سيرفر ولا اشتراك: يستخدم حساب GitHub نفسه الذي رفعت عليه الموقع.

## التركيب (مرة واحدة)

1. أنشئ مستودعاً جديداً على GitHub باسم مثل `playmax-admin` وارفع كل محتويات هذا المجلد (أقل من 100 ملف، دفعة واحدة).
2. من **Settings → Pages** اختر `Deploy from a branch` ثم `main` و `/(root)`، واضغط Save.
3. افتح الرابط الذي يعطيك إياه GitHub (مثل `https://ACCOUNT.github.io/playmax-admin/`) من هاتفك:
   - **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
   - **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
4. أنشئ رمز الدخول (Token):
   - افتح https://github.com/settings/personal-access-tokens/new
   - **Repository access** ← `Only select repositories` ← اختر مستودع **الموقع** ومستودع **التطبيق**.
   - **Permissions ← Contents** ← `Read and write`.
   - اضغط **Generate token** وانسخه.
5. في تطبيق الإدارة افتح **الإعدادات**، واكتب اسم حسابك والرمز واسمَي المستودعين، ثم اضغط «تحقّق واربط».
6. (مستحسن) عيّن **رمز قفل** من 4 أرقام من الإعدادات.

## الأقسام

| القسم | ماذا تفعل فيه |
| --- | --- |
| الرئيسية | عدد التغييرات غير المنشورة وزر «انشر على الموقع والتطبيق» |
| الماكينات | تغيير السعر، إخفاء، حذف واسترجاع، إضافة ماكينة جديدة بصورها ومواصفاتها ووصفها باللغات الأربع |
| العروض والأخبار | شريط العروض المتحرك (عروض، رؤية الشركة، آراء زبائن حقيقية، الجملة)، الأخبار، عنوان الصفحة الرئيسية، كلمات ممنوعة في السوق |
| السوق | إعلانات الزبائن: تعديل، حذف، حظر الناشر، رفع الحظر، البلاغات (يحتاج Firebase — الخطوات داخل القسم) |
| المزيد | أسعار الشحن، رسوم التركيب، أرقام وحسابات التواصل، ربط GitHub، رمز القفل، النسخ الاحتياطي |

## الاستخدام اليومي

- **الماكينات:** غيّر السعر مباشرة من القائمة، أو أخفِ أي ماكينة بالمفتاح. اضغط على الماكينة للتعديل الكامل: الصور، الاسم، الترجمات، المواصفات والوصف.
- **إضافة ماكينة:** زر «إضافة ماكينة جديدة»، ثم اختر القسم وأضف الصور والسعر.
- **الأخبار والعروض:** تظهر في الصفحة الرئيسية للموقع والتطبيق، بلغة كل زبون.
- **الشحن والتواصل:** أسعار الشحن لكل دولة، رسوم التركيب، رقم الواتساب والتيليجرام الذي تصل إليه الطلبات، وروابط إنستغرام وتيك توك وفيسبوك.
- كل تعديل يُحفظ على جهازك أولاً. لا يراه الزبائن حتى تضغط **«انشر على الموقع والتطبيق»** من الرئيسية.

## الأمان

- الرمز محفوظ على هاتفك فقط وليس داخل أي ملف على GitHub. من دون الرمز لا يستطيع أحد النشر حتى لو عرف رابط لوحة التحكم.
- إذا فقدت الهاتف: احذف الرمز فوراً من GitHub (Settings ← Developer settings ← Personal access tokens)، ثم أنشئ رمزاً جديداً.
- اجعل صلاحية الرمز للمستودعين فقط كما في الخطوات أعلاه.
- لوحة التحكم مخفية عن محركات البحث (`noindex`) وغير مربوطة من الموقع.

## حدود هذه النسخة

- يظهر التحديث بعد النشر خلال دقيقة تقريباً، وهو وقت تجهيز GitHub Pages.
- إعلانات «السوق» التي ينشرها الزبائن ما زالت تُحفظ على جهاز كل زبون فقط. لكي يراها الجميع، ولتتمكن من مراجعتها وحذفها من لوحة التحكم، تحتاج قاعدة بيانات مثل Firebase، وهذه هي الخطوة التالية المقترحة.
